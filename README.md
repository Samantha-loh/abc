# 🌍 Clive Hercules Tan - Earth & Country Quiz Game

A fun, interactive, and educational geography quiz game built specially for 5-year-old **Clive Hercules Tan**!

Inspired by classic kid-friendly geography games ("Dan's Countries" / "Stack the Countries"), featuring animated cartoon country and continent shapes with googly eyes, celebratory confetti explosions, encouraging audio chimes, fun facts after every answer, and a personalized explorer certificate.

---

## 🌟 Game Highlights

- **Personalized Voice Greeting**:
  > *"Hi Clive Hercules Tan, let's see how much you know about our Earth home’s countries, land and seas.”*
- **3 Difficulty Levels**:
  - 🌱 **Easy Explorer (10 Questions)**: Continents, major oceans, iconic countries (Egypt, Japan, China), and colors of Earth.
  - 🚀 **Medium Adventurer (25 Questions)**: Boot-shaped Italy, Canada’s lakes, Brazil’s Amazon rainforest, Eiffel Tower, ancient Olympics in Greece, and wildlife.
  - 👑 **Advanced Master (50 Questions)**: High-level trivia for young YouTube geography buffs: Vatican City, Lesotho enclave, deepest Mariana Trench, Caspian Sea, Iceland volcanoes, double-landlocked countries, Nepal's unique flag, and more!
- **Celebration Confetti & Sound Effects**:
  - **Correct Answer**: Bright confetti particle shower + fanfare cheering sound.
  - **Incorrect Answer**: Playful, encouraging chime + gentle highlighting so Clive learns happily.
  - **Grand Finale**: Continuous fireworks and confetti cannon celebration regardless of results!
- **💡 Kid-Friendly Fun Facts**:
  - Every single question provides an engaging fun fact read aloud by the narrator.
- **🗺️ Bonus Game: Continent Explorer**:
  - Interactive map where Clive can tap each continent or ocean to hear its name and fun facts.
- **🏆 Official Explorer Certificate**:
  - Displays Clive Hercules Tan's Certificate with stars earned and an option to print or save.

## 🚀 How to Run Locally

You can run this project with any local web server:

```bash
# Option 1: Using Ruby (built-in on macOS)
ruby -run -ehttpd . -p8080

# Option 2: Using Python 3
python3 -m http.server 8080

# Option 3: Using Node / npx
npx serve .
```

Then open your browser to:
👉 **[http://localhost:8080](http://localhost:8080)**

## 🛠️ Technology Stack
- **HTML5 & Vanilla CSS**: Tactile, kid-friendly design system with starry night backdrop, responsive layouts, and bouncy 3D buttons.
- **Vanilla JavaScript (ES Modules)**: Fast, lightweight game loop.
- **Web Audio API**: Real-time synthesized cheering fanfare, applause sparkles, encouraging chimes, and pops.
- **Web Speech API**: Integrated text-to-speech reader for questions, options, and fun facts.
- **Canvas Particle Engine**: High-performance multi-colored confetti and fireworks.
